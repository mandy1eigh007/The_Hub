How one message gets to the Hub

flowchart LR
  M[Mandy talks] --> C[Claude local session]
  M --> H[Codex safe hook]
  C --> B[Local bridge]
  H --> F[Codex local feed]
  F --> B
  B --> CT[Claude Tail]
  B --> XT[Codex Tail]
  CT --> CITY[A Tale of Two Agents]
  XT --> CITY

What each piece is doing

Claude local session

The existing bridge reads the active Claude session and sends the useful message lines to Claude Tail.

Codex safe hook

Codex records only your prompt and its final answer in a small local feed. It does not read the full transcript.

Local bridge

The bridge delivers both feeds to the Hub database, where the three views can filter or merge them.

What is captured

  • Your Codex prompt
  • Codex’s final answer
  • A timestamp and session label so the order stays clear

What stays out

  • Tool calls and tool output
  • Environment or terminal output
  • Full transcript files
  • Token-like strings and credential assignments are redacted before the feed is written
